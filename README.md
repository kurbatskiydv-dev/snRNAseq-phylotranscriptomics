This repository contains a Python-based pipeline for phylotranscriptomic analysis of human brain single-nucleus RNA-seq data. The workflow is focused on neuronal nuclei from the adult human brain and combines transcriptomic profiles with evolutionary gene annotations. The pipeline includes preprocessing of AnnData objects, normalization and log-transformation of expression values, selection of highly variable genes, principal component analysis, UMAP visualization, integration of evolutionary indices, calculation of Transcriptome Age Index values, comparison of anatomical brain regions and annotated cell types, Gene Ontology enrichment analysis, and automated cell type annotation using MapMyCells reference mapping.

Input data include snRNA-seq expression matrices from the Allen Institute human brain atlas and additional bulk RNA-seq data from the Human Protein Atlas for comparison of anatomical regions. The workflow was developed primarily with Scanpy, pandas, NumPy and related Python tools
